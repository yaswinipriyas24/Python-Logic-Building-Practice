## My Learning Approach

For each coding problem, I follow these steps:

1. **Understand the problem:** Identify what the question is asking.
2. **Identify the input and expected output:** Work through a small example.
3. **Build the logic:** Break the problem into smaller steps.
4. **Write the code:** Convert the logic into Python.
5. **Dry run:** Trace the code manually to understand how each line works.
6. **Test:** Check the solution with different inputs.
7. **Review:** Note the concepts and mistakes so I can improve.

I focus on understanding the logic rather than memorising solutions.
